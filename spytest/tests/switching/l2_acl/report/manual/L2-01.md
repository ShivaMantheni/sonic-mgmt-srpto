## Issues Encountered

### Issue #1: sonic-cli TTY Requirement

**Severity**: HIGH - Test Blocker
**Category**: CLI Environment Limitation

**Description**:
The sonic-cli command requires TTY (terminal) for interactive configuration mode. Non-TTY SSH connections (standard sshpass/paramiko approach) fail when attempting to enter configuration mode:

```
$ sshpass -p 'sonic@123' ssh admin@192.168.100.137 "sonic-cli"
sonic-cli
sonic# configure terminal
sonic(config)#

[At this point, subsequent commands fail with:]
$ sshpass -p 'sonic@123' ssh admin@192.168.100.137 "sonic-cli < config_file.txt"
the input device is not a TTY
```

**Root Cause**:
- sonic-cli uses interactive TTY features for command parsing and prompt handling
- Non-TTY stdin (piped commands) are rejected by the TTY device requirement
- Each SSH connection is stateless; multi-command sequences fail

**Attempted Workarounds**:
1. ✗ `sshpass ssh ... "sonic-cli < config.txt"` - Failed (no TTY)
2. ✗ Python paramiko with invoke_shell() - Failed (command rejection in config mode)
3. ✗ expect script with -tt flag - Failed (TTY handshake issues)
4. ✗ sonic-cli -c flag chaining - Not documented/not supported

**Impact**:
- Cannot programmatically configure device via non-interactive SSH
- Manual configuration via terminal or expect script required
- Blocks automated testing workflow

**Resolution Options**:
1. Use expect script with proper TTY handling (recommended)
2. Use serial console access (if available)
3. Use REST/gNMI API (if implemented on device)
4. Manual terminal configuration (less reliable)
5. Contact vendor for non-TTY CLI support

### B. Scapy Traffic Generator

**File**: `l2_01_tx.py`

```python
#!/usr/bin/env python3
"""
L2-01 Traffic Generator - Permit Source MAC Test
Sends L2 frames with permitted source MAC from external TX host
"""

from scapy.all import Ether, IP, ICMP, sendp
import time
import sys

def main():
    # Configuration
    TX_INTERFACE = "eth0"
    TX_MAC = "00:AA:AA:AA:AA:01"  # Permitted source MAC
    RX_MAC = "00:BB:BB:BB:BB:02"  # RX host MAC (or broadcast)
    PACKET_COUNT = 10
    INTER_PACKET_DELAY = 0.05  # 50ms

    # Create packet
    packet = Ether(src=TX_MAC, dst=RX_MAC) / IP(src="10.0.0.1", dst="20.0.0.2") / ICMP()

    print(f"=== L2-01 Traffic Generator ===")
    print(f"TX Interface:  {TX_INTERFACE}")
    print(f"Source MAC:    {TX_MAC}")
    print(f"Dest MAC:      {RX_MAC}")
    print(f"Packet Count:  {PACKET_COUNT}")
    print(f"Packet Delay:  {INTER_PACKET_DELAY} sec")
    print(f"=====================================\n")

    # Send packets
    try:
        print(f"[TX] Sending {PACKET_COUNT} packets...")
        for i in range(PACKET_COUNT):
            sendp(packet, iface=TX_INTERFACE, verbose=False)
            print(f"  [{i+1:2d}/{PACKET_COUNT}] Packet sent")
            time.sleep(INTER_PACKET_DELAY)

        print(f"\n[SUCCESS] TX Count: {PACKET_COUNT}/{PACKET_COUNT}")
        return 0

    except Exception as e:
        print(f"\n[ERROR] {e}")
        return 1

if __name__ == "__main__":
    sys.exit(main())
```

#!/bin/bash
# L2-01 RX Verification - Capture permitted MAC traffic

RX_INTERFACE="eth1"

echo "=== L2-01 RX Verification ==="

from scapy.all import rdpcap
import sys

try:
    pcap = rdpcap("l2_01_capture.pcap")
    rx_count = len(pcap)
    tx_count = 10
    pass_rate = (rx_count / tx_count) * 100 if tx_count > 0 else 0

    print(f"  RX Count:   {rx_count}/{tx_count}")
    print(f"  Pass Rate:  {pass_rate:.1f}%")

    if rx_count >= 9:
        print(f"  [PASS] RX ≥ 9 (90% threshold)")
        sys.exit(0)
    else:
        print(f"  [FAIL] RX < 9 (below 90% threshold)")
        sys.exit(1)

except Exception as e:
    print(f"  [ERROR] {e}")
    sys.exit(1)
EOFPY

echo ""
