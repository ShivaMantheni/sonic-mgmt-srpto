# BoilerPlate — SPYTest Project Scaffold

Portable setup for any networking QA project. Run this once per repo; safe to re-run (creates only what is missing, updates only what is incomplete).

---

## 1. Folders (create if absent)

| Folder | Role |
|--------|------|
| `@tests/QA-Docs/` | HOW — QA rules, templates, standards |

Do not duplicate or rename these folders if they already exist.

---

## 2. Files (create or patch)

| Path | Action |
|------|--------|
| `@CLAUDE.md` | Create if missing; if present, ensure **Routing** and **QA MODE** sections match §3 below without removing unrelated project rules |
| `@tests/QA-Docs/TestPlan_Template.md` | Create if missing; do not overwrite an existing customized template |
| `@tests/QA-Docs/QA_Rule.md` | Create if missing; test-case standards for `/qa` TC generation |
| `@TestBuilder.md` (repo root) | Create if missing; Processes 1–4 pipeline for plan, TCs, validation, RTM |

| `assets/workguide_diagrams/` | PNG sources for diagrams (regenerated by build script) |

---

## 3. `CLAUDE.md` — required blocks

Ensure these blocks exist (merge, do not duplicate headings):

**Routing (prefix gate)**

- Prompt starts with `/qa` (any variant) → **QA MODE**
- Otherwise → normal coding assistant
- No bleed-over between modes

**QA MODE**

1. Read all files under `@tests/QA-Docs/` and `@tests/automation/<feature>/ProjDoc/` before answering or generating artifacts.
2. Ground every output in those sources; no generic filler.
3. Write new QA artifacts only under `reports/` (versioned, append-only; do not edit prior runs in place).

**Knowledge zones**

- `@tests/QA-Docs/` = HOW 

Use the project’s `CLAUDE.md` as source of truth once written; this BoilerPlate only defines the minimum.

---

## 4. `@tests/QA-Docs/TestPlan_Template.md`

If missing, create from the networking test-plan template bundled with this scaffold (deadlines, in-scope; out-of-scope section reserved for later).

---

## 5. Agent execution checklist

```
FOR each folder in [@tests/QA-Docs]:
  IF NOT exists → mkdir

IF NOT exists CLAUDE.md → write full routing file (§3 + header)
ELSE → patch missing §3 sections only

IF NOT exists @tests/QA-Docs/TestPlan_Template.md → copy template
```

Stop when checklist passes. Do not add extra folders, samples, or docs beyond this list.
